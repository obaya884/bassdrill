# Bass Drill

ベースの基礎練習を止まらずに一周させる伴走画面。開けば今日のキーが決まっていて、指板に音名と度数が載っていて、先生の代わりに度数を出題し、ダイアトニック・ノンダイアトニックのコードを並べる。PC のブラウザで使う、サーバーを持たない静的な Web アプリ（Vite + React）。

- [要求定義書](./docs/仕様/11_要求定義書.md) — 何のために・何を・何をしないか
- [要件定義書](./docs/仕様/12_要件定義書.md) — 要求ごとの挙動の規則と技術方針
- [画面定義書](./docs/仕様/13_画面定義書.md) — 画面の構成・寸法・色・文言

本番: https://bassdrill.vercel.app

## 使い方

PC では両手はベースに置いたまま、キーボードだけで進める。スマホ（幅 1024px 未満、またはタッチ主体の端末）では 1 画面 1 節のページ送りになり、左右スワイプか点の両脇の ‹ › で節を移り、下のボタンで操作する。指板は横スクロール。ヘッダーのキーをタップするとキーを選べる。

| キー | 操作 |
|---|---|
| `J` / `K`（`↓` / `↑`） | 次の節 / 前の節 |
| `←` / `→`（`H` / `L`） | コードの順送り（節 4・6・7） |
| `Space` / `Enter` | 答えを表示 / 次の問題（節 5） |
| `M` | メジャーペンタ / マイナーペンタの切り替え（節 3） |
| `A`、`+` / `-` | 自動送りの切り替え、間隔（2〜15 秒） |
| `N` | 次のキー（同じ日は 12 キーを使い切るまで重複しない） |
| `?` | キー操作の一覧 |

## 開発

Node 22 以上。

```sh
npm install
npm run dev        # http://localhost:5173
npm test           # vitest run
npm run build      # dist/ に静的ファイルを出す
```
