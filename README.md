# Bass Drill

ベースの基礎練習を止まらずに一周させる伴走画面。開けば今日のキーが決まっていて、指板に音名と度数が載っていて、先生の代わりに度数を出題し、ダイアトニック・ノンダイアトニックのコードを並べる。PC のブラウザで使う、サーバーを持たない静的な Web アプリ（Vite + React）。

- [要求定義書](./docs/仕様/11_要求定義書.md) — 何のために・何を・何をしないか
- [要件定義書](./docs/仕様/12_要件定義書.md) — 要求ごとの挙動の規則と技術方針
- [画面定義書](./docs/仕様/13_画面定義書.md) — 画面の構成・寸法・色・文言

本番: https://bassdrill.vercel.app

## 使い方

開くと今日のキーが決まっている。見えているものをクリック・タップ・スクロール・スワイプするだけで進める（キーボードショートカットは無い）。

- **キーを変える**: ヘッダーのキーをクリック／タップ → 12 キーから選ぶか「次のキー」（同じ日は 12 キーを使い切るまで重複しない）。PC は 5 度圏の図からも選べる
- **PC**: 6 節が縦に並ぶ。マウスでスクロールして読み進める
- **スマホ**（幅 1024px 未満、またはタッチ主体の端末）: 1 画面 1 節。左右スワイプか点の両脇の ‹ › で節を移る。指板は横スクロール
- **コード**: 表の行をクリック／タップすると指板がそのコードになる
- **度数**: カードの「答え」で答えを表示、「次」で次の問題
- **ペンタ**: 「メジャー / マイナー」で切り替え

## 開発

Node 22 以上。

```sh
npm install
npm run dev        # http://localhost:5173
npm test           # vitest run
npm run build      # dist/ に静的ファイルを出す
```
