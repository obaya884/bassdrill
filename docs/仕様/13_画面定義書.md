## 1. 画面の構成

S-01 は縦 1 ページ。上下は固定で、中央だけがスクロールする。

```
┌──────────────────────────────────────────────────────────────┐
│ 上部固定  節 3 / 7 ペンタトニック        [5 度圏]   G♭  2 / 12 │  ← 現在地（F-503）・5 度圏（F-103）・今のキー・順列の位置（F-102）
├──────────────────────────────────────────────────────────────┤
│                                                              │
│   1 キー            （非フォーカス: 減光・縮小）              │
│   2 メジャースケール                                          │
│ ▶ 3 ペンタトニック  （フォーカス: 拡大・画面縦中央）          │
│   4 セブンスコード                                            │
│   5 度数                                                      │
│   6 ダイアトニック                                            │
│   7 ノンダイアトニック                                        │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│ 下部固定  J/K 節  ←/→ コード  Space 答え  M ペンタ  A 自動  N 次のキー  ? ヘルプ │  ← ショートカット（F-502）
└──────────────────────────────────────────────────────────────┘
```

- 想定する横幅は 1280px 以上（N-03）。中央の内容幅は最大 1200px で中央寄せ
- 上部固定の高さは 88px。左に現在地、中央に今のキー（§5 の `key` サイズ）、右に 5 度圏（§4）と順列の位置 `k / 12`
- 下部固定の高さは 40px。ショートカットは §6 の表記で 1 行。`?` で同じ内容を大きく重ねて出し、もう一度 `?` か `Esc` で閉じる

## 2. 節ごとの配置

節の番号・順・見出しは §6。各節は見出し（左上）＋本体。本体の形は 3 種類。

| 節 | 本体 |
|---|---|
| 1 キー | 今のキーを `key-hero` サイズで中央に 1 文字（例 `G♭`）。その下に小さく `今日のキー` または `手で選んだキー`（F-104 で選んだとき） |
| 2 メジャースケール | 指板（§4）1 枚。マーカーの中は音名、下にキー度数 1〜7。根音は `root` 色 |
| 3 ペンタトニック | 見出しの右に `C メジャーペンタ` / `A マイナーペンタ` の現在名（§6）。指板 1 枚。マイナーのとき根音は 6 度の音、度数ラベルは根音から数え直す（F-202） |
| 4 セブンスコード／6 ダイアトニック／7 ノンダイアトニック | 左 40% にコード表（下記）、右 60% に選択中コードの指板。節 7 は見出しの下に §6 のガイド文を `muted` 色で 1 行 |
| 5 度数 | 問題文を `quiz` サイズで中央に。答え表示では問題文の下に答えを同じサイズ・`accent` 色で出す。その下に指板（基準＝`root` 色、答え＝`tone` 色の 2 音だけ）。右上に `自動送り: オン 5 秒` / `自動送り: オフ` を `muted` 色で |

**コード表**: 1 行 1 コード。外れ音の強調は節 7 だけ（F-303。節 4 の m7 などスケール外の音を含むコードでも、節 4・6 では強調しない）。列は ローマ数字（`muted`）・コードネーム（`ink`、太字）・構成音 4 つ。構成音のセルは上段に音名、下段にコード度数を小さく。選択行は背景 `surface-raised`、左端に 3px の `accent` の縦線。外れ音のセルは文字を `outside` 色にして下線（色だけに頼らない。N-05 の趣旨）

## 3. フォーカスの見せ方

- フォーカス節: 不透明度 1、`transform: scale(1)`、見出し `heading-focus` サイズ
- 非フォーカス節: 不透明度 0.35、`transform: scale(0.92)`（`transform-origin: top center`）、見出し `heading` サイズ。指板・表はそのまま描く（読めなくてよい）
- 切り替えは `opacity` と `transform` の 200ms ease-out トランジション
- フォーカスが移ったら、その節が画面縦中央に来るよう `scrollIntoView({ block: 'center', behavior: 'smooth' })`
- 節の間隔は 64px。ページ先頭と末尾には上下固定の高さ分の余白を取り、1 節目・7 節目も中央に来られるようにする

## 4. 指板と 5 度圏の描画

**指板**（SVG。`viewBox` 固定で親幅いっぱいに伸ばす）

- `viewBox` は `0 0 1040 260`。左 56px は弦名の列、残り 984px を 13 列（0〜12 フレット）で割る（1 列 ≒ 75.7px）
- 弦は上から G D A E の 4 本、弦間 56px、上下に 28px の余白（弦の y は 50・106・162・218）。線は `line` 色で、太さは G 1.5px → E 3px と下に向かって太く
- フレット線は各列の右端に縦線（`line` 色、1px）。0 フレット（ナット）の右端だけ 4px
- ポジションマーク: 3・5・7・9 フレットの列の中央、指板の縦中央に直径 18px の `line` 色の点（マーカーの度数ラベルと重なっても読めるよう薄く大きく）。12 フレットは 2 点（上から 2 本目と 3 本目の弦の間、3 本目と 4 本目の間）
- マーカー: 列の中央・弦の上に直径 40px の円。`kind` ごとに塗り `tone`→`accent`、`root`→`root`、`outside`→`outside`。根音は加えて 3px の `ink` の縁。円の中に音名（`fret-note` サイズ、`bg` 色の文字、太字）。度数ラベルは円の下 14px に `fret-degree` サイズ・`muted` 色
- 弦名は左の列に `fret-degree` サイズ・`muted` 色

**5 度圏**（SVG）

- 直径 56px の円の外周に 12 キーを時計回り（12 時が C）。各キーは直径 22px のボタン。今のキーは直径 28px・塗り `accent`・文字 `bg` 色、他は塗り `surface-raised`・文字 `ink`。上部固定に収めるため小さく、1 m 離れて読むものではない（今のキーは中央の `key` サイズの文字で読む）
- 順列で次に来るキーの表示はしない（F-103 の任意項目は採らない）

## 5. デザイントークン

`src/index.css` の `@theme` に同じ名前で写す。

| トークン | 値 | 用途 |
|---|---|---|
| `--color-bg` | `#0e0f12` | 背景 |
| `--color-surface` | `#16181d` | 上下固定・コード表の面 |
| `--color-surface-raised` | `#20232a` | 選択行・5 度圏のボタン |
| `--color-line` | `#2c3038` | 弦・フレット線・区切り |
| `--color-ink` | `#ececf1` | 文字 |
| `--color-muted` | `#8b8f9a` | 補助文字・度数ラベル・ガイド文 |
| `--color-accent` | `#f2b544` | スケール音・コードトーンのマーカー、今のキー、答え |
| `--color-root` | `#5ad1f0` | 根音のマーカー |
| `--color-outside` | `#f06a6a` | 外れ音 |
| `--font-sans` | `"Inter", system-ui, sans-serif` | 全文字。Google Fonts の Inter 1 書体（N-01・N-06）。♯♭𝄫 は system-ui にフォールバック |

文字サイズ（px。N-05 の下限を満たす）

| 名前 | 値 | 用途 |
|---|---|---|
| `key-hero` | 160 | 節 1 のキー |
| `key` | 40 | 上部固定の今のキー |
| `quiz` | 56 | 節 5 の問題文と答え |
| `heading-focus` | 32 | フォーカス節の見出し |
| `heading` | 24 | 非フォーカス節の見出し |
| `chord-name` | 24 | コード表のコードネーム |
| `chord-tone` | 20 | コード表の音名 |
| `fret-note` | 18 | 指板の音名（`viewBox` 座標。実寸は横幅に比例） |
| `fret-degree` | 13 | 指板の度数ラベル・弦名・コード表のコード度数 |
| `ui` | 14 | 現在地・ショートカット・補助表示 |

## 6. 文言

| 場所 | 文言 |
|---|---|
| 節の見出し | `1 キー` / `2 メジャースケール` / `3 ペンタトニック` / `4 セブンスコード` / `5 度数` / `6 ダイアトニック` / `7 ノンダイアトニック` |
