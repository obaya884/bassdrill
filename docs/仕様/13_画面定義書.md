## 1. 画面の構成（PC 表示）

S-01 は縦 1 ページ。上部は固定で、中央がスクロールする。下部の固定部は無い。

```
┌──────────────────────────────────────────────────────────────┐
│ 上部固定                G♭ ▾                                   │  ← ヘッダー 88px。キーはボタン（F-104）
├──────────────────────────────────────────────────────────────┤
│   メジャースケール                                             │
│   （指板）                                                     │
│                                                              │
│   ペンタトニック   C メジャーペンタ  [メジャー / マイナー]        │
│   （指板）                                                     │
│                                                              │
│   7th コード（四和音）（コード表 ｜ 指板）                       │
│   度数            （問題カード ［答え］）（指板）                 │
│   ダイアトニック   （コード表 ｜ 指板）                          │
│   ノンダイアトニック（ガイド文、コード表 ｜ 指板）                │
└──────────────────────────────────────────────────────────────┘
```

- 想定する横幅は 1280px 以上（N-03）。中央の内容幅は最大 1200px で中央寄せ
- ヘッダーの高さは 88px。左端にアプリ名 `Bass Drill`（18px、`muted`）、中央に今のキー（`key` サイズ。ボタン。右に小さな `▾`）と、その下に `今日のキー` / `手で選んだキー`。他の要素は置かない（5 度圏の図・現在地・`k / 12` は持たない）
- 6 節はすべて等倍で、減光・拡大・現在地の強調はしない。節の間隔は 64px。ページ先頭はヘッダー分の余白、末尾は 40vh の余白（最後の節も画面の上半分で読める）
- キーボードショートカット・ショートカット行・ヘルプは持たない（F-502）

## 2. 節ごとの配置（PC 表示）

節の順・見出しは §6。番号は付けない。各節は見出し（左上、`heading` サイズ）＋本体。本体の形は 3 種類。

| 節 | 本体 |
|---|---|
| メジャースケール | 指板（§4）1 枚。マーカーの中は音名、下にキー度数 1〜7。根音は `root` 色 |
| ペンタトニック | 見出しの右に `C メジャーペンタ` / `A マイナーペンタ` の現在名（`heading` サイズ、`muted`）と `メジャー / マイナー` ボタン。指板 1 枚。マイナーのとき根音は 6 度の音、度数ラベルは根音から数え直す（F-202） |
| 7th コード（四和音）／ダイアトニック／ノンダイアトニック | 左 40% にコード表（下記）、右 60% に選択中コードの指板。ノンダイアトニックは見出しの下に §6 のガイド文を `muted` 色で 1 行 |
| 度数 | 問題カード（§2.1）と、その下に指板（基準＝`root` 色、答え＝`tone` 色の 2 音だけ） |

**コード表**: 1 行 1 コード。列は ローマ数字（`muted`）・コードネーム（`ink`、太字）・構成音 4 つ。構成音のセルは上段に音名、下段にコード度数を小さく。行全体がクリックの対象（カーソルはポインタ）。選択行は背景 `surface-raised`、左端に 3px の `accent` の縦線。外れ音の強調はノンダイアトニックだけ（F-303。セブンス・ダイアトニックではスケール外の音を含むコードでも強調しない）: 文字を `outside` 色にして下線（色だけに頼らない。N-05 の趣旨）

### 2.1 問題カード（度数）

- 幅いっぱいの面（`surface`、角 16px）。中央に問題文（`quiz` サイズ）。答え表示では問題文の下に答えを同じサイズ・`accent` 色で出す
- カードの右下に 1 つのボタン（高さ 44px、`accent` の塗り、`bg` の文字、`button` サイズ）。出題中は `答え`、答え表示中は `次`（F-403）
- カードの他の場所は押しても何も起きない

## 3. キー選択の面（F-104）

- ヘッダーのキー（ボタン）をクリックすると、キーの真下にポップオーバーが開く（幅 360px、`surface`、角 16px、`line` の枠、影なし）。見出し `キーを選ぶ`
- **5 度圏の円**（§4）: 直径 300px の箱に、半径 122px の円周上へ 12 キーのボタン（直径 48px、20px の文字）を時計回り（12 時が C）に置く。隣との中心間は約 63px で、今のキー（直径 56px）とも重ならない。今のキーは `accent` の塗り・`bg` の文字、他は `surface-raised`・`ink`。円の中央に今のキーの名前（`key` サイズ、`accent`）
- 円の下に幅いっぱいの `次のキー` ボタン（高さ 44px、`surface-raised`）
- キーを選ぶか `次のキー` を押すと閉じる。面の外をクリックしても閉じる
- スマホ表示では同じ中身を下から出るシートで出す（§8.6）

## 4. 指板と 5 度圏の描画

**指板**（SVG。`viewBox` 固定で親幅いっぱいに伸ばす）

- `viewBox` は `0 0 1040 260`。左 56px は弦名の列、残り 984px を 13 列（0〜12 フレット）で割る（1 列 ≒ 75.7px）
- 弦は上から G D A E の 4 本、弦間 56px、上下に 28px の余白（弦の y は 50・106・162・218）。線は `line` 色で、太さは G 1.5px → E 3px と下に向かって太く
- フレット線は各列の右端に縦線（`line` 色、1px）。0 フレット（ナット）の右端だけ 4px
- ポジションマーク: 3・5・7・9 フレットの列の中央、指板の縦中央に直径 18px の `line` 色の点（マーカーの度数ラベルと重なっても読めるよう薄く大きく）。12 フレットは 2 点（上から 2 本目と 3 本目の弦の間、3 本目と 4 本目の間）
- マーカー: 列の中央・弦の上に直径 40px の円。`kind` ごとに塗り `tone`→`accent`、`root`→`root`、`outside`→`outside`。色以外の手がかり（N-05）として、根音は 3px の `ink` の実線の縁、外れ音は 2px の `ink` の破線の縁（`6 4`）。**根音がスケール外のとき**（♭VIM7・♭VII7 の根音）は塗り `outside` に 3px の破線の縁で、「外れ音」と「根音」の両方を示す。円の中に音名（`fret-note` サイズ、`bg` 色の文字、太字）。度数ラベルは円の下 14px に `fret-degree` サイズ・`muted` 色
- 弦名は左の列に `fret-degree` サイズ・`muted` 色

**5 度圏**（キー選択の面の中。§3・§8.6）

- 寸法は §3（直径 300px の箱、半径 122px、ボタン 48px、今のキー 56px）。今のキーは塗り `accent`・文字 `bg` 色、他は塗り `surface-raised`・文字 `ink`。円の中央に今のキーの名前
- 順列で次に来るキーの表示はしない。ヘッダーには置かない（2026-11-05 に小さすぎて読めないため移した。[決定ログ](./log_13_画面定義書.md)）

## 8. スマホ表示（幅 1024px 未満、またはタッチ主体）

要件定義書 §5.7 の見え方。§1〜§3 は PC 表示の定義で、スマホ表示は本節が上書きする。トークン（§5）と文言（§6）は共通。

### 8.1 画面の構成

```
┌──────────────────────────┐
│          [ G♭ ▾ ]          │  ← ヘッダー 56px（＋安全領域）。キーはボタン（F-104）
│       ‹ ○ ○ ● ○ ○ ○ ›      │  ← ページの点 28px。両脇に ‹ ›（F-601）
├──────────────────────────┤
│                          │
│   （1 節ぶんの本体）        │  ← 横スワイプで前後の節。縦はスクロール
│                          │
└──────────────────────────┘
```

- 下部の固定バーは無い（F-602）。本体は画面の下端まで使い、安全領域の下端ぶんは本体の余白にする
- 本体は縦スクロール可（横持ちでは固定部 84px を引いた残りに収まらないので縦スクロールで見る）。横方向は節のページ送りに使う（指板の上を除く）
- 6 節を横一列に並べた帯を `transform` で動かす。帯と各節（スクロールコンテナ）に `touch-action: pan-y` を付け、横のパンはブラウザに渡さず Pointer Events で受ける
- 安全領域（ノッチ・ホームバー）は `env(safe-area-inset-*)` でヘッダーの高さと左右の余白に足す（`index.html` の viewport に `viewport-fit=cover`）
- ヘッダーは左端にアプリ名 `Bass Drill`（12px、`muted`）、中央にキー（`key-sp` サイズ、ボタン、右に `▾`）と、その下に `今日のキー` / `手で選んだキー`（11px、`muted`）。現在地の文字や `k / 12` は無い

### 8.2 節ごとの本体

| 節 | 本体 |
|---|---|
| スケール・ペンタ | 見出し（`heading-sp`）。ペンタは見出しの下に現在名と `メジャー / マイナー` ボタン（高さ 44px）。その下に指板（§8.3） |
| セブンス・ダイアトニック・ノンダイアトニック | 上にコード表（§8.4）、下に選択中コードの指板。ノンダイアトニックは見出しの下にガイド文（`ui` サイズ、`muted`） |
| 度数 | 問題カード: 問題文を `quiz-sp` サイズで中央に、答え表示はその下に `accent` 色で同サイズ、カード右下に `答え` / `次` ボタン（高さ 44px、幅 96px 以上）。カードの下に指板（基準と答えの 2 音） |

### 8.3 指板

- PC と同じ SVG（§4 の `viewBox 0 0 1040 260`）を幅 `max(100%, 820px)` の箱に入れ、箱の親を `overflow-x: auto` にする。縦持ち（約 390px）では 5〜6 列、横持ち（約 840px）では全列が見える
- スクロールの初期位置は左端。節を移ったら左端に戻す
- 箱の親は `overflow-x: auto` のままブラウザのスクロールに任せる（`touch-action` は `pan-x pan-y`）。ページ送りのスワイプ判定（§8.5）は、開始点の要素がこの箱の中なら無視する（`closest` で判定）
- マーカーの文字は `viewBox` 座標で PC と同じ（18px・13px）。箱が 820px 以上なので実寸でも 14px 以上になる

### 8.4 コード表

- 列は ローマ数字・コードネーム・構成音 4 つ。構成音は音名だけを `chord-tone-sp` サイズで。**選択中の行だけ**、音名の下にコード度数を `fret-degree` サイズで出す（F-605）
- 行の高さは 44px 以上（セルの上下の余白で確保する）。行のタップで選択。選択行は PC と同じ（`surface-raised`＋左の `accent` 線）。外れ音はノンダイアトニックだけ `outside` 色＋下線（§2 と同じ）
- 8 行で 352px。縦持ちでは固定部 84px・見出し・ガイド文と合わせて 1 画面に収める。溢れる機種は本体の縦スクロールで見る（F-605 の「1 画面」は表の全行が見えることを指し、指板まで同時に見えることは求めない）

### 8.5 ページ送り

- 横スワイプ（Pointer Events）: 開始点が指板の箱の外で、横移動が 48px 以上かつ縦移動より大きいとき、指を離した時点で前後の節へ移る（節の切り替えは離した時点。追随中は変えない）。移動中は帯を指に追随させ、離したら 200ms で収める。帯の外で離してもよい（window で受ける）
- 点: 6 つ、直径 8px、いまの節は `accent`、他は `line`。両脇の `‹` `›` は 44px のタップ領域
- 節が変わると本体の縦スクロールは先頭に戻る

### 8.6 キー選択シート（F-104・F-604）

- 画面下から出る面（`surface`、上角 16px の丸み）。見出し `キーを選ぶ`。中身は PC のポップオーバーと同じ（§3 の 5 度圏の円と `次のキー`）
- キーを選ぶか `次のキー` でシートは閉じる。シートの外（背景 `bg` の 80% 不透明）をタップでも閉じる
- シートが開いている間、帯のスワイプは効かない
