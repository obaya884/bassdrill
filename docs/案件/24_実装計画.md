> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 要求定義書 §6 の Must／Should をすべて満たす練習画面（S-01）を Vercel に置き、オーナーが自主練で開ける状態にする。

**Architecture:** 音楽理論はすべて `src/domain/` の純粋関数（React も Date も知らない）に置き、12 キー全件の期待値表で守る。画面は `src/components/`（指板・5 度圏・コード表・出題）を `src/app/App.tsx` が 7 節に並べ、キー入力と localStorage は `src/app/` のフックが受ける。ビルド成果物は `dist/` の静的ファイルだけ。

**Tech Stack:** Vite 7 / React 19 / TypeScript 5 / Tailwind CSS 4（`@tailwindcss/vite`）/ Vitest 5 + jsdom + `@testing-library/react` / Vercel（framework preset: Vite）。Node 26（手元）。

## Global Constraints

- 音名の記号は `♯` `♭`（U+266F / U+266D）。`#` `b` を表示に使わない（N-07）。ダブル変化記号は画面に出さない（F-305）
- 12 キーの綴りと 5 度圏の順は `C G D A E B G♭ D♭ A♭ E♭ B♭ F`（F-103・F-105）
- 指板は弦 4 本を上から `G D A E`、フレットは `0〜12` の 13 列（F-201・F-203）
- 文字の暫定下限: 指板の音名 18px、出題と答え 48px、フォーカス中の節の見出し 32px（N-05）
- domain は I/O・`new Date()`・`Math.random()` を直接呼ばず引数で受ける（要件定義書 §2.3）。テストの無い導出を画面に出さない（N-04）
- 画面文言は日本語、コードネーム・度数記号は英語表記（N-07）
- 通信はビルド成果物の取得だけ。サーバー・DB・認証を持たない（N-02）
- コミットメッセージは日本語の Conventional Commits（`feat:` `test:` `docs:` `chore:`）。末尾に `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`

## Review Focus

仕様が明示しないが、使う人が踏みやすい入力と、期待される挙動。各行のテストは所有タスクに入れてある。

1. **JST の日付境界**（UTC 15:00 以降）: 通算日は Asia/Tokyo の暦日で数え、23:59 と 0:00 で今日のキーが切り替わる（Task 6）
2. **12 日ブロックの境目**: 前ブロック末尾と次ブロック先頭が同じキーなら入れ替わり、2 日連続の同一キーが無い（Task 6）
3. **localStorage が壊れている／別の日付**: JSON が壊れていても、日付が昨日でも、既定値（位置 0・手の選択なし・5 秒）で起動しエラーにしない（Task 11）
4. **節 5 以外での `Space`**: ページがスクロールせず、出題の状態も動かない（Task 13）
5. **コード一覧の端**: 先頭で `←`、末尾で `→` を押しても巡回せず止まる（Task 12）

### Task 2: 音名とピッチクラス（`pitch.ts`）

**Files:**
- Create: `src/domain/pitch.ts`, `src/domain/pitch.test.ts`
- Delete: `src/domain/smoke.test.ts`

**Interfaces:**
- Produces:
  - `type Letter = 'C'|'D'|'E'|'F'|'G'|'A'|'B'`、`const LETTERS: readonly Letter[]`（C から順）
  - `type NoteName = Readonly<{ letter: Letter; accidental: -2|-1|0|1|2 }>`
  - `note(letter: Letter, accidental?: number): NoteName`
  - `pitchClass(n: NoteName): number`（0〜11。C=0、E=4、B♭=10、C♭=11、B♯=0）
  - `formatNote(n: NoteName): string`（`'C'` `'F♯'` `'B♭'` `'E𝄫'` `'F𝄪'`。𝄫 は U+1D12B、𝄪 は U+1D12A）

  - `hasDoubleAccidental(n: NoteName): boolean`
  - `equalsNote(a: NoteName, b: NoteName): boolean`
