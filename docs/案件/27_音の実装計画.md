# 音を鳴らす（F-306・F-406・F-506）実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 音の入切ボタンを入にしたとき、コード表の行タップで構成音（低い順に 1 音ずつ → 4 音を重ねる）、度数の「答え」で基準 → 答えの 2 音が鳴る。

**Architecture:** 「何を・どの高さで・何秒ずつ鳴らすか」は `src/domain/sound.ts` の純粋関数が `SoundStep[]` として組み、12 キー全件のテストで守る。Web Audio で実際に鳴らすのは `src/app/audioPlayer.ts`（`AudioContext` を狭い型で受け、偽物でテストする）と、それを入切の状態と結ぶ `src/app/useSound.ts`。`useDrillState` が `selectChord` と `quiz.advance` の中で鳴らし、ヘッダーのボタン `SoundToggle` は `components/` に置く。

**Tech Stack:** Vite 8 / React 19 / TypeScript 7 / Vitest 5 + jsdom + Testing Library。Web Audio API（`AudioContext`・`OscillatorNode`・`GainNode`）。依存の追加なし。

**Spec:** [要求定義書](../仕様/11_要求定義書.md) §6 F-306・F-406・F-506 と §7、[要件定義書](../仕様/12_要件定義書.md) §5 F-306・F-406・F-506・F-502・N-04、[画面定義書](../仕様/13_画面定義書.md) §1.1・§8.1・§6。

## Global Constraints

- 依存方向は domain ← components ← app。domain は React も Web Audio も知らない
- 音源ファイルを持たない。外部ライブラリを足さない（N-01・N-06）
- 入切は保存しない（N-02）。`localStorage` に触れない
- 既定は**切**。切のときは何も鳴らず、既存のテストの挙動は一切変わらない
- `keydown` を購読しない（F-502）
- 鳴らす処理（Web Audio）は jsdom に無いので、`AudioContext` は引数で注入し、偽物でテストする。実機の音色・音量の調整は最後の Task で行う
- コミットメッセージは `type(scope): 日本語の要約`。コミットの末尾に `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`
- テストは `npx vitest run <file>`、型検査は `npx tsc -p tsconfig.app.json --noEmit`、lint は `npm run lint`

## Review Focus

1. 入のまま別の行を連打しても音が重ならない（前の音を止めてから鳴らす）。Task 3 のテストで止める呼び出しを確認する
2. 入 → 切に戻した瞬間、鳴っている音が止まる。Task 4 のテストで確認する
3. `AudioContext` が無いブラウザ（`window.AudioContext` が `undefined`）で入にしても落ちず、何も鳴らない。Task 4 のテストで確認する
4. 読み替えのある根音（F♯m7♭5・AM7 など）でも 4 音が低い順に並ぶ（音名の綴りではなくピッチクラスで積む）。Task 1 の 12 キー全件テストで確認する
5. 答えの音は基準より高い（半音数 2〜11 の範囲）。Task 1 のテストで 8 音程 × 7 基準 × 12 キーを回す

### Task 1: domain/sound.ts — 高さと鳴らす段取り

**Files:**
- Create: `src/domain/sound.ts`
- Test: `src/domain/sound.test.ts`

**Interfaces:**
- Consumes: `NoteName`・`pitchClass` (`src/domain/pitch.ts`)、`Chord` (`src/domain/chord.ts`)、`IntervalId`・`INTERVAL_SPEC` (`src/domain/quiz.ts`)、`KEYS` (`src/domain/scale.ts`)、`keySevenths`・`diatonicChords`・`nonDiatonicChords` (`src/domain/progression.ts`)
- Produces:
  - `type SoundStep = Readonly<{ midis: number[]; seconds: number }>` — 同時に鳴らす MIDI ノート番号の列と長さ（秒）
  - `frequency(midi: number): number` — A4（69）= 440 Hz の平均律
  - `rootMidi(root: NoteName): number` — 根音の MIDI 番号。E2（40）〜 E♭3（51）に収める（要件 F-306）
  - `chordSound(chord: Chord): SoundStep[]` — 5 段。最初の 4 段は 1 音ずつ 0.3 秒（`chord.tones` の順＝根音から上へ 1 オクターブ内に積む）、5 段目は 4 音同時に 1.0 秒
  - `quizSound(base: NoteName, interval: IntervalId): SoundStep[]` — 2 段。基準 0.5 秒 → 答え（基準 + 半音数）0.7 秒
  - `CHORD_NOTE_SECONDS = 0.3`・`CHORD_BLOCK_SECONDS = 1.0`・`QUIZ_BASE_SECONDS = 0.5`・`QUIZ_ANSWER_SECONDS = 0.7`（定数として export。実機調整で変えたら要件定義書 F-306・F-406 も直す）

```ts
// src/domain/sound.test.ts
import { describe, it, expect } from 'vitest'
import { note, pitchClass, formatNote } from './pitch'
import { KEYS, majorScale } from './scale'
import { keySevenths, diatonicChords, nonDiatonicChords } from './progression'
import { INTERVALS, INTERVAL_SPEC } from './quiz'
import { frequency, rootMidi, chordSound, quizSound, CHORD_NOTE_SECONDS, CHORD_BLOCK_SECONDS, QUIZ_BASE_SECONDS, QUIZ_ANSWER_SECONDS } from './sound'

describe('frequency', () => {
  it('A4 = 440 Hz、C4 ≈ 261.63 Hz、1 オクターブで 2 倍', () => {
    expect(frequency(69)).toBe(440)
    expect(frequency(60)).toBeCloseTo(261.63, 2)
    expect(frequency(52) / frequency(40)).toBeCloseTo(2, 6)
  })
})

describe('rootMidi', () => {
  it('E は 40、E♭ は 51 で、12 キーすべて 40〜51 に収まりピッチクラスが合う', () => {
    expect(rootMidi(note('E'))).toBe(40)
    expect(rootMidi(note('E', -1))).toBe(51)
    for (const k of KEYS) {
      const m = rootMidi(k)
      expect(m).toBeGreaterThanOrEqual(40)
      expect(m).toBeLessThanOrEqual(51)
      expect(m % 12).toBe(pitchClass(k))
    }
  })
  it('異名同音は同じ高さ（F♯ と G♭）', () => {
    expect(rootMidi(note('F', 1))).toBe(rootMidi(note('G', -1)))
  })
})

describe('chordSound', () => {
  it('12 キー × 19 コードで、4 音を低い順に 1 音ずつ 0.3 秒、最後に 4 音同時 1.0 秒', () => {
    for (const k of KEYS) {
      for (const x of [...keySevenths(k), ...diatonicChords(k), ...nonDiatonicChords(k)]) {
        const steps = chordSound(x.chord)
        expect(steps, formatNote(k) + ' ' + x.chord.name).toHaveLength(5)
        const midis = steps.slice(0, 4).map((s) => s.midis[0])
        expect(midis).toEqual([...midis].sort((a, b) => a - b))
        expect(midis[0]).toBe(rootMidi(x.chord.root))
        expect(midis[3] - midis[0]).toBeLessThan(12)
        midis.forEach((m, i) => expect(m % 12).toBe(pitchClass(x.chord.tones[i].note)))
        steps.slice(0, 4).forEach((s) => expect(s.seconds).toBe(CHORD_NOTE_SECONDS))
        expect(steps[4]).toEqual({ midis, seconds: CHORD_BLOCK_SECONDS })
      }
    }
  })
})

describe('quizSound', () => {
  it('12 キー × 7 基準 × 8 音程で、基準 0.5 秒 → 答え 0.7 秒。答えは基準より半音数ぶん上', () => {
    for (const k of KEYS) {
      for (const base of majorScale(k)) {
        for (const iv of INTERVALS) {
          const steps = quizSound(base, iv)
          expect(steps).toEqual([
            { midis: [rootMidi(base)], seconds: QUIZ_BASE_SECONDS },
            { midis: [rootMidi(base) + INTERVAL_SPEC[iv].semitones], seconds: QUIZ_ANSWER_SECONDS },
          ])
        }
      }
    }
  })
})
```

- Create: `src/app/audioPlayer.ts`

**Interfaces:**
- Consumes: `SoundStep`・`frequency` (Task 1)
- Produces:
  - `type AudioContextLike = { currentTime: number; destination: AudioNode; state: string; resume(): Promise<void>; createOscillator(): OscillatorNode; createGain(): GainNode }` — 使うものだけに絞った `AudioContext` の型（`BaseAudioContext` のサブセット）
  - `type Player = { play(steps: SoundStep[]): void; stop(): void }`
  - `createPlayer(ctx: AudioContextLike): Player` — `play` は前の音を止めてから（`stop()` と同じ）全段を `ctx.currentTime` 起点で予約する。段ごとに `midis.length` 個の `OscillatorNode`（`type = 'triangle'`、`frequency.value = frequency(midi)`）を 1 つの `GainNode` に繋ぎ、`gain` は立ち上がり 0.01 秒で `0.3 / midis.length`、段の終わり 0.05 秒前から 0 へ下げる。`osc.start(at)`・`osc.stop(at + seconds)`。`stop` は予約済みの全 `OscillatorNode` に `stop(ctx.currentTime)` を呼び、`GainNode` の `gain` を今の時刻で 0 にして `disconnect` する

### Task 3: app/useSound.ts — 入切の状態と鳴らす入口

**Files:**
- Create: `src/app/useSound.ts`
- Test: `src/app/useSound.test.ts`

**Interfaces:**
- Consumes: `createPlayer`・`AudioContextLike`・`Player` (Task 2)、`SoundStep` (Task 1)
- Produces:
  - `type SoundState = { enabled: boolean; toggle(): void; play(steps: SoundStep[]): void }`
  - `useSound(options?: { createContext?: () => AudioContextLike | null }): SoundState` — `enabled` の初期値は `false`。`toggle` は `enabled` を反転し、入にするときに `createContext()` で `AudioContextLike` を**初回だけ**作って（`useRef` に持つ）`resume()` を呼び、切にするときは `player.stop()`。`play` は `enabled` が真で `player` があるときだけ `player.play(steps)` を呼ぶ。`createContext` の既定は `typeof window.AudioContext === 'function' ? () => new window.AudioContext() : () => null`。`createContext()` が `null` を返したら `enabled` は真になるが何も鳴らない（音が出せない環境では黙る。要件 F-306）
